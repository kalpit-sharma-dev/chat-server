# Universal Financial Statement Analysis System

## 1. **Objective**

Design an end-to-end solution that can automatically parse, normalize, analyze, and generate insights from **any type of financial statement**, including:

* Bank account statements
* Credit card statements
* Demat (holding + transaction) statements
* Loan statements
* Wallet statements (Paytm, PhonePe, etc.)

The system should support **PDF, Excel, CSV, Image (OCR)** formats and follow a unified analysis flow.

---

## 2. **High-Level Architecture (Flow Diagram Description)**

### **Step 1: Input Upload Layer**

* User uploads file(s)
* Supported formats: PDF, Image, Excel, CSV
* Multi-page, password-protected PDFs supported

### **Step 2: Pre-processing Layer**

1. **File Type Detection**
2. **Password Unlock (If required)**
3. **OCR Extraction** (Tesseract / AWS Textract / Google Vision)
4. **Text Structuring**

   * Header extraction
   * Table detection
   * Line-item identification

### **Step 3: Statement Classifier**

ML/Rule-based classifier identifies:

* Bank Statement
* Credit Card Statement
* Demat Holding
* Demat Trades
* Loan EMI Statement
* Wallet Statement

### **Step 4: Template Mapping & Normalization**

Each statement type has different formats. So create:

* **Document Templates**
* **Field Extractor Rules**
* **Column Mapper** → Convert to **Universal Schema**

Example universal schema for transactions:

* date
* description
* category
* debit
* credit
* balance
* source (HDFC, SBI, Upstox, Zerodha, etc.)
* confidence score

### **Step 5: Data Cleaning Layer**

* Detect duplicates
* Normalize dates (dd-mm-yyyy → yyyy-mm-dd)
* Standardize amounts
* Description cleanup
* Category suggestions using ML

### **Step 6: Analysis Engine**

#### **Bank & Credit Card**

* Expense Categorization
* Income Classification
* Recurring Payments Detection
* Cash Flow Health Score
* Credit Utilization
* EMI Tracker
* Suspicious Transactions

#### **Demat**

* Portfolio Allocation
* Unrealized P/L
* Realized P/L
* Trade Patterns
* SIP & Lump Sum summary
* XIRR returns

### **Step 7: Insights & Reporting Layer**

* Summary Dashboard
* Monthly Summary Report
* Investment Report
* Cashflow Trends
* Alerts & Flags

### **Step 8: Output Layer**

* JSON Output
* Summary PDF
* Graphs (Bar/Pie/Line)
* API output for app integration

## 4. **Rules for Statement Analysis**

### **1. Date Rules**

* Identify all possible patterns
* Extract nearest valid date
* Validate year logic (e.g., 2030 unlikely)

### **2. Amount Rules**

* Debit/Credit inference based on keywords
* Negative amounts normalized
* Currency detection

### **3. Category Rules**

* ML + Rule-based hybrid
* Example rules:

  * "UPI", "Paytm", "GPay" → Digital Payments
  * "Amazon" → Shopping
  * "NACH", "SI" → Auto Debit
  * "ATM" → Cash Withdrawal

### **4. Duplicate Detection Rules**

* Same date + same amount + same description = probable duplicate
* Fuzzy matching for descriptions

### **5. Fraud/Suspicion Rules**

* Multiple high-value transactions in short time window
* Transactions at odd hours
* Sudden cash withdrawals
* Abnormal credit utilization (>80%)
